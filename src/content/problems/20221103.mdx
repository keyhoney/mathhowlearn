## 문제

등차수열 $\{ a_{n}\}$에 대하여



$$
a_{2} = 6, a_{4} + a_{6} = 36
$$



일 때, $a_{10}$의 값은? \[3점\]



① $30 $ ② $32 $ ③ $34 $ ④ $36 $ ⑤ $38 $







## 힌트

등차수열이면 $a_{n} = a_{1} + (n-1)d$로 쓸 수 있어요. $a_{2}=6$과 $a_{4}+a_{6}=36$을 각각 $a_{1}$, 공차 $d$에 대한 식으로 바꿔 보세요.



## 힌트

$a_{1}$, $d$에 대한 연립방정식을 풀면 $a_{1}$과 $d$가 정해져요. 그다음 $a_{10} = a_{1} + 9d$로 구하면 됩니다.



## 풀이

등차수열 $\{ a_{n}\}$의 첫째항을 $a_{1}$, 공차를 $d$라 하면



$a_{n} = a_{1} + (n-1)d$



로 쓸 수 있어요.



$a_{2} = 6$이므로



$a_{1} + d = 6$



이에요.



또 $a_{4} = a_{1} + 3d$, $a_{6} = a_{1} + 5d$이므로



$a_{4} + a_{6} = 36$에서



$(a_{1} + 3d) + (a_{1} + 5d) = 36$



$2a_{1} + 8d = 36$



양변을 $2$로 나누면



$a_{1} + 4d = 18$



이에요.



이제 $a_{1} + d = 6$과 $a_{1} + 4d = 18$을 빼 볼게요.



$(a_{1} + 4d) - (a_{1} + d) = 18 - 6$



$3d = 12$



따라서 $d = 4$이고, $a_{1} + 4 = 6$에서 $a_{1} = 2$예요.



$a_{10} = a_{1} + 9d = 2 + 9 \times 4 = 2 + 36 = 38$



따라서 정답은 **⑤**예요.
