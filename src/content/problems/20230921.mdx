## 문제
그림과 같이 곡선 $y = 2^{x}$ 위에 두 점 $P(a,   2^{a})$, $Q(b,   2^{b})$이 있다. 직선 $PQ$의 기울기를 $m$이라 할 때, 점 $P$를 지나며 기울기가 $- m$인 직선이 $x$축, $y$축과 만나는 점을 각각 $A$, $B$라 하고, 점 $Q$를 지나며 기울기가 $- m$인 직선이 $x$축과 만나는 점을 $C$라 하자.
$\overline{AB} = 4\overline{PB}$, $\ \overline{CQ} = 3\overline{AB}$일 때, $90 \times (a + b)$의 값을 구하시오. (단, $0< a< b$) \[4점\]

![](/images/docx2mdx/230921-20260602-124609/media/image8.webp)


## 힌트
$\overline{AB}=4\overline{PB}$는 점 $P$를 중심으로 한 닮음비를 줘요. $y=2^x$ 위 두 점의 $y$좌표 비가 $1:4$가 되도록 $b=a+2$인지 확인해 보세요.


## 힌트
$PQ$의 기울기 $m$을 $a$로 나타낸 뒤, 점 $P$를 지나고 기울기가 $-m$인 직선의 $y$절편(점 $B$)을 구해 보세요.


## 힌트
$\overline{AB}=4\overline{PB}$에서 $y$축 방향 길이 비로 $\overline{OB}:\overline{OP}=4:3$ 같은 닮음 조건을 세우면 $a$에 대한 일차방정식을 얻을 수 있어요. $a$를 구한 뒤 $b=a+2$로 $90(a+b)$를 계산하세요.

## 풀이

$2^{a} :  2^{b} = 1 :  4$에서 $2^{b} = 2^{a + 2}$, $b = a + 2 P(  a,    2^{a}),    Q(  a + 2,    2^{a + 2})$라 할 때,

기울기 $m = \frac{2^{a + 2} - 2^{a}}{2} = 3 \times 2^{a - 1}$

직선 $AB$의 방정식은

$y = - 3 \times 2^{a - 1}(x - a) + 2^{a}$에서 $y$절편은

$3a \times 2^{a - 1} + 2^{a}$

닮음비에 따라 $3a \times 2^{a - 1} + 2^{a}:  2^{a} = 4:  3$가 성립하므로

$2^{a + 2} = 9a \times 2^{a - 1} + 3 \times 2^{a}$,

$2^{a}$으로 양변을 나눠주면

$4 = \frac{9}{2}a + 3,    a = \frac{2}{9}$,

$b = a + 2$이므로 $b = \frac{20}{9} \therefore    90 \times (a + b) = 90 \times \frac{22}{9} = 220$
